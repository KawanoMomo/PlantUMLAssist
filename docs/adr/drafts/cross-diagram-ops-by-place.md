# (ドラフト・未採番) 図をまたぐ操作は図を名前ではなく居場所 (フォルダの道と名前) で見分ける

- 状態: 提案 (TICKET-roadmap-20261123-0226-1 で実装、TICKET-roadmap-20261123-0226-2 で記録。roadmap v7.0 必須 2「置換が木の全体へ届く」。採番は人間)
- 日付: 2026-11-23
- 関係: ドラフト `subfolder-doc-place.md` (サブフォルダの図のタブは居場所を持つ) の続き。`save-dir-ownership-v6.md` (保存先に書くのは `.puml` と押した書き出しだけ) を守る

## 文脈
⇄ 部品名を一括置換する (Ctrl+H) の「開いていない図も数える」は、開いているタブと保存先の直下の `.puml` を
**名前で 1 つに畳んで** (同じ名前なら開いている方が勝つ) 数え、開いていない図へはその名前で保存先へ書き戻していた。
v6.0 でサブフォルダの図を開けるようにしたため、直下の `a.puml` と `hw/a.puml` は同じ名前の別のファイルになった。
置換を木の全体へ広げるとき、名前で畳む持ち方のままでは (a) 直下の `a` を開いていると `hw/a` が開いている側に吸い込まれて
数えられず書き換わらない (当てたはずの図が黙って外れる)、(b) 書き戻し先を名前で決めると `hw/a` の置換結果が直下の `a.puml` に書かれる
(押していない図が書き換わる)。どちらも data-loss。

## 決定
- 図をまたぐ操作 (今は ⇄ 一括置換の数え・一覧・開いていない図への書き戻し) は、図を **居場所の鍵** で見分ける。
  鍵は `folderImpact.keyOf(name, subDir)`: 直下の図は名前そのまま (前からの一覧・過去の置換の組と同じ)、
  サブフォルダの図は `sub:{フォルダの絶対パス (区切りは / ・小文字)}|{名前}` (前回保存版の基準 `sub:…|名前` と同じ形)。
- 開いているタブも同じ鍵で並べる (タブの `sub`・`dir` から作る)。鍵が同じなら開いている方 (未保存の編集を含む) が勝つ。
  直下とサブフォルダの同じ名前は別の行。
- 画面の行は、サブフォルダの図だけを保存先からの道付き (`hw/a`・`hw/spi/b`) で出す。直下の図は名前だけ (前の画面と同じ)。
- 開いていない図への書き戻しは、その図の行が持つフォルダ (サブフォルダの図はそのフォルダ、直下の図は保存先) へ書く。
  改行コード・BOM は上書きする相手のファイルから引き継ぐ (server の `POST /autosave` の既定)。
- 置換した開いていない図はタブの Ctrl+Z が効かないので、直前の 1 回の置換の前後を **画面の中だけ** に持ち、
  窓の「置換前に戻す (未オープン N 枚)」で戻す。戻すのは今のファイルが置換後と同じ図だけ (後から直された図は戻さず名前を言う)。
  保存先に控え・印を置かない。
- 木の読み方は v6.0 の `GET /tree-dir` (読むだけ) と `GET /autosave?type=&dir=` (1 枚を読む) をそのまま使い、server に口を足さない。

## 却下した案
- 名前に道を含める (`hw/a` を図の名前にする): 名前の規則 (パス区切りを使わない) と保存の口を広げることになる。`subfolder-doc-place.md` と同じ理由。
- サブフォルダの図を置換の的から外したまま、画面に「直下だけ」と書き続ける: v7.0 の軸 (1 件の変更を木のどこの図にも取りこぼさず反映する) を満たさない。
- 戻すための前の中身を保存先 (`_renames/` 等) に置く: 保存先に `.puml` と押した書き出しのほかを書かない約束 (v7.0 必須 1) を破る。
  版の控え (この図の履歴) で戻す案は、サブフォルダの図の版の通しが直下と揃うまで (TICKET-roadmap-20261123-0226-4) 1 回では戻せない。

## 影響
- 鍵を持たない入力 (直下だけ) では前と同じに名前で畳むので、前からの unit・e2e・過去の置換の組はそのまま通る。
- 名前で突き合わせる別の仕組み (保存の入れ替わりの検知) には、読み込んだ図を居場所 (rel) 付きで渡し、`saveSwap.placed` が
  直下の図は直下の図とだけ、サブフォルダの図は道付きの名前 (`design/spi`) で全部と比べる (TICKET-roadmap-20261123-0226-4)。
- 保存フォルダの一覧・最近開いた図は直下の図だけのまま (roadmap v7.0「やらない」)。
- 確かめ: `tests/scenarios/roadmap-20261123-0226-1.spec.js` (同じ名前の 2 枚・CRLF・バイト一致・戻す)、`tests/roadmap-20261123-0226-1-tree-rename.test.js` (名前で畳むと落ちる)。

# (ドラフト・未採番) サブフォルダの図はタブが居場所を持ち、名前の一意性は同じフォルダの中だけで求める

- 状態: 提案 (TICKET-roadmap-20261122-0855-2。roadmap v6.0 必須 3「サブフォルダをツリーで扱う」。採番は人間)
- 日付: 2026-11-22

## 文脈
保存は「図の名前 = ファイル名 (`{名前}.puml`)」で、タブ (workspace の 1 ドキュメント) は名前だけで引かれていた。
同じ名前のタブを開くと `-2` を付けて一意にし、一覧から同じ名前を開くと既にあるタブへ移って中身を読み直す。
サブフォルダの図を FILES から開けるようにすると、直下の `gpio_seq.puml` と `design/api/gpio_seq.puml` は
同じ名前の別のファイルになる。名前だけで引けば (a) 片方を開くともう片方のタブの中身が差し替わり、そのタブの書き先へ
書かれる、(b) `-2` を付けると `gpio_seq-2.puml` という無いファイルへ書く。どちらも押していない図が変わる・増える。

## 決定
- サブフォルダから開いた図のタブは `dir` (そのフォルダの絶対パス) と `sub: true` を持つ。保存・自動保存・`!include`・
  書き出しの置き場はタブの `dir` で決める (保存先を替える前に開いたタブを留める `dir` と同じ道)。
- タブを引く・名前を一意にするのは「居場所」(サブフォルダの図はそのフォルダ、ほかは今の保存先) の中だけ。
  `findByName` は直下の図だけを返し、居場所込みで引くのは `findOpen({ name, sub, dir })`。
- 前回保存版 (save-diff) の基準は、サブフォルダの図では `sub:{フォルダ}|{名前}` で持ち、直下の同じ名前の図と分ける。
- 名前で引く操作 (ツリーの名前変更・削除・移動、タブ・図の設定からの名前の変更の付け替え、保存の入れ替わり検知、
  「最近開いた図」) はサブフォルダの図に当てない。名前の変更はまだ受けず、理由を出して断る (付け替えは直下を相手にするため)。
- ツリーは server の `GET /tree-dir?dir=` (読むだけ。隠しフォルダと `_versions` は出さない) で実在の階層を読む。

## 却下した案
- 名前に道を含める (`design/api/gpio_seq` を図の名前にする): 名前の規則 (パス区切りを使わない) と server の保存の口
  (`type` は素のファイル名) を両方広げることになり、名前を打つ欄・控えの鍵・Git の印まで道を解くことになる。
- サブフォルダの図を開くたびに保存先をそのフォルダへ替える: 前のフォルダが「読むだけ」に回り、2 つのフォルダの図を
  行き来して直せない (票の「現状」そのもの)。

## 影響
- 一覧・最近開いた図・⇄ 一括置換の「保存フォルダの直下の全ファイル」は直下の図だけを数える (画面にそう書く)。
- サブフォルダの図の名前の変更・移動・削除は必須 4 (TICKET-roadmap-20261122-0855-3) で、居場所込みの操作として足す。

# (ドラフト・未採番) 保存先は「利用者が開いたフォルダとその下」。書くのは `.puml` と押した書き出しだけ

- 状態: 提案 (TICKET-roadmap-20261122-0855-4。roadmap v6.0 必須 5・クライテリア 6。採番は人間)
- 日付: 2026-11-22
- 関係するドラフト: `subfolder-doc-place.md`(タブが居場所を持つ)、`export-into-save-dir.md`(書き出しの置き場)、`tree-ops-retarget-open-tab.md`(移動・名前変更でタブを付いていかせる)、`folder-state-outside-save-dir.md`(保存先の外に状態を持つ)

## 文脈
v5.0 までの保存先は「1 つのフォルダの直下の `*.puml`」で、保存先の下のフォルダは扱わず、書き出しはダウンロードで受け、
フォルダを作る・図を別のフォルダへ移すには エクスプローラ が要った。v6.0 は「フォルダで仕事をする版」で、
利用者の Git 作業木をそのまま保存先にして、その中で図を開き・直し・整え・書き出すところまでを製品の中で終える。
一方で、保存先は利用者の作業木そのものなので、製品が勝手にファイルを置くと差分に混ざり、押していない図が変わると data-loss になる。

## 決定
- **保存先の範囲**: 利用者が窓で選んだ 1 つのフォルダと、その下の実在のフォルダ。保存先の外(親・隣)は「読むだけ」節で見るだけにし、書かない。
  保存先の選び方は 1 つの窓 (フォルダを辿る。パスの手打ちもできる) に寄せ、選ぶ・辿るだけではどのフォルダにも書かない。
- **図の居場所**: 図は「フォルダ + 名前 (`{名前}.puml`)」で決まる。タブはその居場所を持ち、保存・自動保存・`!include`・書き出しの既定の置き場は居場所から決める。
  名前の一意性は同じフォルダの中だけで求める (直下とサブフォルダの同じ名前の図は別の図)。
- **保存先に書くもの**: `.puml`(利用者が直した図・作った図・移した図)、利用者が押した書き出し (`{名前}.svg`・`{名前}.png`・`{名前}.transparent.png`)、
  利用者が右クリックで作ったフォルダ。どれも押した 1 つだけで、他のファイルはバイト一致のまま。
- **保存先に置かないもの**: 版の控え (この図の履歴)、書き出し先の記憶、最近開いた図、保存先の印や設定、ツールの控え。
  これらはマシンの設定の置き場とブラウザに持つ (`PUA_DATA_ROOT` の下と localStorage)。
- **消す・上書きする**: 図の削除は押した 1 枚だけで、消す直前の中身を版に控えて「この図の履歴」から戻せる。
  移動・名前変更・書き出しの行き先に同じ名前の図があれば (書き出しの上書きを除き) 断る。フォルダを丸ごと消す入口は作らない。
- **直下だけを数える機能**: 保存フォルダの一覧・最近開いた図・⇄ 一括置換の「保存フォルダの直下の全ファイル」は直下の図だけを数え、画面にそう書く (黙って広げない・黙って外さない)。

## 却下した案
- 保存先の中に `.plantumlassist/` のような設定・控えのフォルダを置く: 利用者の Git の差分に混ざり、「保存先に書くのは `.puml` と押した書き出しだけ」に反する。
- 図の名前に道を含める (`design/api/gpio_seq`): 名前の規則と server の保存の口を広げることになる (`subfolder-doc-place.md`)。
- 書き出しを常にダウンロードで受ける: 利用者が毎回、保存先へ移し替えていた (roadmap v6.0 の根拠)。

## 影響
- 製品仕様書 `docs/spec/product-spec.md` の「製品の約束」は v5.0 のまま変えない。「フォルダで図を扱う」「書き出す」はこの持ち方で書く。
- 一覧・⇄ 一括置換・GIT 節をサブフォルダへ広げるかは v6.0 の後の願望と批評で決める。

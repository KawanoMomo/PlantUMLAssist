## 該当ありの2件

### 8. キーボードで図に入れない — **最も重い**

05 では **61ラウンド見逃した Blocker** で、06 でも同じ状態です。

```
Tab×20: btn-open → btn-save → btn-config → btn-zoom-out → btn-zoom-in
        → btn-zoom-fit → btn-export → btn-render → render-mode → diagram-type → editor
図らしき要素に届く: いいえ
エディタで Escape → editor (動かない)
```

05 での直し方は**経路を1本足すだけ**でした:

- `focusPreview()` 相当 (`tabindex="-1"` を付けて `focus()`) を用意する
- エディタでの `Escape` からそれを呼ぶ (エディタの Escape は無反応なので奪う操作が無い)
- 移った先で何が効くかを案内する
- ヘルプ表に行き先を書く (書いていない操作は探せない)

**注意**: 06 のエディタが Tab を字下げに使っているかは未測定です。
使っていないなら、素直に `tabindex` を付けて Tab 順に入れる方が良い可能性があります。
**05 の解法をそのまま持ち込む前に、06 の Tab の扱いを測ってください。**

### 5. 版の刻印

06 には `VERSION` ファイルが無く、画面にも版がありません。

05 では、利用者からの不具合報告に対し**どの版の話かの特定に調査の大半を費やしました**
(作業ツリーが 74 コミット遅れていた)。同じことが 06 でも起こり得ます。

05 での直し方: ステータス行に版を出し、**`VERSION` との一致をテストで固定**する
(人が2箇所を揃え続けるのは必ず失敗する)。

## 該当なしの2件 — なぜ当てはまらなかったか

### 1. モジュール直下の可変状態

05 では 21 モジュール中 2 つ (`block` / `c4`) が「最後に使った親」を覚えており、
文書を跨いで残っていました。**06 は 6 モジュールすべてで直下変数が 0 件**です。

これは 06 が優れているというより、**モジュール数が少なく機能もまだ薄い**ためと考えられます。
パネルに「前回の値を覚える」機能を足すときに、**同時に捨てる仕組みも用意してください**。

### 2. 契約経路の引数落ち

05 では 8 件検出し、うち 1 件 (`c4`) が実害でした。06 は 0 件です。

ただし 05 の検査は `operations.{add,update,delete,moveUp,moveDown,connect}` の
入口だけを見ています。06 の入口は 6 個しか無いので、**機能が増えたら再実行してください**。
走査スクリプトは 05 側にあります。

## 06 でこれから検査器を作る場合の注意 (C95 / C96 より)

   製品に無い入口を自分で作っていたため、その欠落を 61 ラウンド見逃した

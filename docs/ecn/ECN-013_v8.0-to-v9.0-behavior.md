## コンテキスト

v8.0 の仕様書と ECN-012 が入った(`e2979fa`)後、v8.0.0 のタグまでに入口の語をそろえる票と、保存先を決めていない画面が図を並べて書き込み先を偽る穴の票が入った。
v8.0.0 の後、v9.0(`loop/roadmap/v9.0.md` は製品の外)は「書き出した 1 枚がそのまま資料に貼って読める版」として進めた。書き出しは願望の一番太い流れで、v6.0 が置き場、v7.0 が古さ、v8.0 が押した時点の図を採り、残ったのが大きさと、v8.0 の「書き出しは今の本文の図」の外に残っていたクリップボードだった:
PNG は SVG の寸法の 1 倍(台本の図は幅 109〜303 px)で資料の本文幅に広げると字がぼけ、大きさを決める所は画面に無かった。「クリップボードにコピー」はプレビューに在る絵をそのまま写し、描き直しの前・エラー中は直前の図を黙って写し、絵が無ければ黙って何もしなかった。
同じ間に owner の批評から、6 図種の「末尾に追加」を開いた直後の From / To と知らせの形をそろえる票が入った。

`releaser: version 7.3.0`(0dcf91a)・`version 8.0.0`(2f9f9fe)は版の印だけで振る舞いを変えない。

守ったこと(どの票でも): 足した設定は Export ▾ の中の「PNG の大きさ:」の 1 つだけで、新しい窓・画面・パネル・書き出しの形式を足していない(入口の語をそろえた票は入口の数を変えていない)。
書き出しのために本文へ `scale`・`skinparam dpi` を書き足さず、SVG のバイト列は倍率に依らず同じ。倍率の記憶はブラウザに持ち、保存先に設定・印を書かない。
空・欠けた PNG と直前の絵・別の図の絵を知らせ無しに書かない・写さない。試験の遅れ(`/render` の応答を 1.5 秒遅らせる)は scenario の中だけで作った。

## 結果

- 製品仕様書は v9.0。前書きに必須 1・2 を「図を資料へ渡す順」に並べ、「書き出す」の v9.0 の 2 行(「PNG の大きさ」「クリップボードにコピーも今の本文の図」)が入口・振る舞い・確かめるを持つ。「製品の約束」の「操作は今の本文に働く」の括弧にクリップボードを足した。各行が指す scenario は `tests/roadmap-20261115-2114-3-product-spec.test.js` が実在と欄の揃いを見張る
- PNG は何も選ばずに SVG の寸法 × 2 で出て、1 か所で替えた倍率が別の図・開き直しの後も同じ(`tests/scenarios/junior-20261123-1142.spec.js`)。クリップボードは描き直しが 1.5 秒遅れても今の本文の図を同じ大きさで写す(`tests/scenarios/roadmap-20261123-2358-1.spec.js`)
- この ECN と ADR ドラフト `png-scale-tool-setting.md` が在ることは同じ unit が見張る

## 教訓

- 1 つの約束(「書き出しは今の本文の図」)を入口ごとに入れると、残った入口(クリップボード)が約束の外に残る。約束を入れる票は、同じ働きの入口を全部数えて名指しする(v9.0 は PNG を出す入口 — PNG・透過 PNG・保存先の一覧のまとめての書き出し・クリップボード — を 1 本の描く道 `_rasterSvgEl` に通した)
- 設定を足す版では、覚える単位(道具に 1 つ / 図ごと / 形式ごと)と置き場(ブラウザ / 保存先 / 本文)を先に決めて ADR ドラフトに残す。決めずに入れると束の図で値が揃わず、本文や Git の差分が書き出しのために動く
- 入口の語をそろえる票は、前の語を検索語に残して引けるようにすると、語を替えても利用者の手が空振りしない
